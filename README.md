A cheerfully confident piece of terrible advice, delivered in the voice of a helpful assistant that has never once questioned its own logic. The ants get a new home, the neighbour gets a new problem, and everyone involved gets to pretend this was a plan all along. It is exactly the kind of tidy, upbeat solution an AI would offer with total certainty — and exactly the kind nobody should follow.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (no trailing newline) and prints its character count (Unicode code points, as the gate counts them).
